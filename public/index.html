Exactly what happens to my data

Metric computation runs on-device in the Presage SmartSpectra SDK. Network access authenticates the API key, validates the subscription and can fetch encrypted model artifacts. Raw camera frames are not uploaded by Aura. Aggregate SDK telemetry is disabled. Metrics live only in this tab’s memory; there are no accounts, cookies, analytics, database or automatic exports. “End & erase” releases the camera and clears the session.
